# 🌱 POST PARA LINKEDIN - Calculadora CO2eq

## 📝 Texto Principal da Postagem

🌱 **Acabei de desenvolver uma ferramenta completa para cálculo de pegada de carbono!**

Como **Engenheiro especializado em sustentabilidade**, criei uma calculadora profissional que não só calcula emissões CO2e, mas também a **energia economizada** através da reciclagem.

🚀 **Principais funcionalidades:**
• 10 tipos de resíduos com fatores científicos precisos
• Cálculo automático de CO2e E energia economizada (kWh)
• Gráficos interativos e relatórios profissionais em PDF
• Interface responsiva e design moderno
• 100% gratuito e open-source

💻 **Stack técnica:**
• JavaScript Vanilla (sem frameworks)
• Canvas API para gráficos
• CSS Grid/Flexbox para layout responsivo
• Deploy automatizado na Vercel

🎯 **Por que essa ferramenta é diferente?**
Além do CO2e tradicional, calculo a **energia economizada** com a reciclagem, mostrando o impacto positivo real. Cada material tem fatores específicos baseados em estudos de LCA (Life Cycle Assessment).

🔗 **Acesse agora:** https://co2eq-calculator.vercel.app

🔧 **Desenvolvi uma aplicação web completa para análise de pegada de carbono**

Como engenheiro, identifiquei uma lacuna no mercado: ferramentas que calculassem não apenas CO2e, mas também o impacto energético positivo da reciclagem.

**🏗️ Solução desenvolvida:**
• Aplicação SPA com JavaScript vanilla
• Algoritmos de cálculo baseados em dados científicos (IPCC, EPA)
• Interface responsiva com Canvas API para visualizações
• Sistema de geração de relatórios profissionais
• Deploy automatizado com CI/CD na Vercel

**📊 Métricas técnicas:**
• 10 tipos de resíduos cobertos
• 2 métricas ambientais calculadas simultaneamente
• Interface 100% responsiva
• Performance otimizada (< 2s load time)

**🎯 Resultados:**
Ferramenta que permite às empresas quantificar precisamente seu impacto ambiental positivo, gerando relatórios técnicos para compliance e reporting.
